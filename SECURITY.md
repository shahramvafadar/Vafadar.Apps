# Security policy

## Supported versions

Security fixes are made for the **latest release** of each app in the stores and for the `main` branch.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub: **Security** tab → **Report a vulnerability** (private vulnerability
reporting). Please include:

* the affected app and version, and the platform (Android / iOS / Windows),
* a description of the problem and its impact,
* steps to reproduce or a proof of concept,
* any suggested fix.

This is a personal project maintained in spare time. You can expect an acknowledgement within a week and a fix or
mitigation as soon as reasonably possible. Please give a reasonable time to fix the issue before disclosing it.

## Scope

In scope: the apps and libraries in this repository, in particular backup encryption, handling of access tokens
and anything that could expose a user's data.

Out of scope: vulnerabilities in third-party services (Google, Microsoft, app stores) or dependencies – please
report those to their maintainers (and let me know if an app is affected).
