# Zanance – requirements

The product is named **Zanance**; the specification and the code use the working name *Finance*
(`src/Apps/Finance`, `Vafadar.Finance.*`, app id `pro.vafadar.finance`).

The requirements are defined by the owner's *Finance Product Specification*, kept in this repository:

* [Finance Product Specification](spec/Finance-Product-Specification.md) – v1.1 (baseline 2026-09-25, revised
  2026-09-26); Section 31 records the implementation status and the deviations.
* [Privacy Matrix Starter](spec/Finance-Privacy-Matrix-Starter.md) – v1.1; the maintained, code-verified matrix is
  [06 – Privacy matrix](06-privacy-matrix.md).

Its identifiers (`PR-*`, `FIN-*`, `ACC-*`, `TX-*`, `CAT-*`, `VIS-*`, `REF-*`, `REC-*`, `REM-*`, `BUD-*`, `FOR-*`,
`DASH-*`, `REP-*`, `LOC-*`, `FX-*`, `UX-*`, `ONB-*`, `IO-*`, `BAK-*`, `SEC-*`, `PRI-*`, `REL-*`, `MAT-*`, `MON-*`,
`F2-*`, `AT-*`) are used throughout the design documents and tests. When the implementation changes what the
specification describes, both the design documents and Section 31 of the specification are updated.

Start with the [design documentation index](README.md).
