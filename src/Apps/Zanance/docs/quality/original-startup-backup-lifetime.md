actual original validation and cancellation guard protected work. Worker validation does

original source and translated warning/buttons must remain unchanged on consent return.

editable field. This is not a managed-memory erasure claim. Only a returned original Stage

cumulative cap and clears temporary chunk/MemoryStream copies on every exit. The returned
package is independent owned memory. Empty input retains its original interpretation;
original protected portable validation decides whether it is a valid backup.
