## Original defects and complete form ownership

replaces a concurrent note, and retrying a new type after its post-commit notification fails creates
another identity. The original view model also mutates its retained source before dimension refusal.

adapter kept in a thin MAUI partial. It reads original type/events/prices coherently from one actual
file; new forms reserve one absent identity for their whole life. Its reviewed writer rechecks file,
publication, fresh create/correction rights, immutable source and exact original pending raw fields.

and consumes known acceptance before fallible notification/return. Entity constructors are not used
to deserialize a fresh replacement identity. There is no schema/model or measurement-scale change.

Raw validation failures remain correctable in the same original form. Changed/departed source retires
Save but preserves raw input and asks for close/reopen; it never silently refreshes away a draft.
Empty native query redelivery keeps the original loaded/failed/accepted identity, and a missing
existing source cannot turn into creation. Known accepted edits/creation disable Save and financial
input, retain the saved identity and offer Close without an unsaved warning. A new type opens the
existing opening-quantity route only once after successful publication; a failed subsequent native
return or notification never repeats creation. No ledger entry is posted by creating a type.
