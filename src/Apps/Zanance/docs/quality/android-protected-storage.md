## Delivered behavior

The official source-built SQLCipher provider is selected before app construction. Covered startup owns
legacy migration and publication of all protected profiles; missing authority never creates a replacement
profile/key or plaintext fallback. One lazy native host supplies the original profile, restore and safety
contracts. Root replacement updates the current protected session source before financial pages appear.

Automatic per-generation Android Keystore keys protect financial databases. Optional recorded recovery
uses standard RSA-3072 wrapping and a separate encrypted private vault. Enrollment requires explicit
acknowledgment, resumes the original vault after interruption and never creates another code when enrolled.
Existing PIN authorization applies independently before key or backup recovery.

Explicit portable recovery validates bounded sources/schema/preferences before native effects, activates
a retained new private root and replays preferences once. Old financial files remain archived. Retirement
captures authenticated exact files/public mappings/aliases before catalogue publication and rechecks
current, archived, recovered and staged references. Financial ancestry and unrelated references survive
safety expiration. Final Android OS backup/transfer exclusion is coupled to this runtime; new devices
restore Zanance backups. Portable file passwords remain optional.
