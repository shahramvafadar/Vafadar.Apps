  a worker. Read and revalidate within one joined deferred SQLite transaction. Preserve
  the complete existing resource and budget fingerprints, including budget definitions.
- Independent command ownership survives changes to shared busy feedback. Kind changes,
  discard prompts, Save, reload and leave remain serialized through their actual native
  transition. The first typed destination cannot change during its pending read.
- Retained pages revalidate the old source before exposing the old row references and
  literal selection. Failed revalidation covers the form and requires explicit retry or
  discard/reload; a display refresh does not silently replace a draft.
- Writer ownership is checked around the actual original SaveChanges and transaction
  commit. The one-use receipt records accepted no-op or commit before fallible Changed
  handlers. A notification failure cannot turn a committed choice into a retryable Save.
- The command's own parent return holds the command lock. Its one-use scope captures
  the actual window root, page, binding owner, immediate parent, stack depth and route.
  A foreign root, forward route, second event or different parent cannot borrow it.
  Actual parent arrival is checked after GoToAsync, which can otherwise complete after
  cancellation. The same correction applies to the original profile discard/leave path;
  D-658 did not qualify that dirty-return branch natively.
