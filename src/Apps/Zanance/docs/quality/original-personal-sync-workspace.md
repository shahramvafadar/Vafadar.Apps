first-run eligibility are read in one joined deferred SQLite transaction, followed by
source/access validation. Existing public reader contracts and conflict policies remain

device responses, row commands, attachment previews and first-run Close. Shared busy
feedback cannot release that ownership. Retired roots, changed disclosure or literal
peer inputs refuse old continuations. A local read-only retry does not reopen network
transport or reread credentials. Failed reads cover the form and preserve literal
nonsecret input for explicit retry.

Known accepted operations are recorded before fallible notification/follow-through.
The new six-language feedback distinguishes a successful primary operation from a
failed refresh; retry reads the source rather than repeating the primary operation.
