## Original consent and failure handling

The outgoing personal payload is at most16KiB and one366-day interval (plus an explicitly disclosed disjoint
previous comparison), at most10,000 selected accounts,64 currencies and100,000 source rows. Bounds refuse,
never silently truncate. Figures reuse LedgerCalculator. The local source fingerprint contains only needed
identity/currency/opening-date/minimal ledger fields; notes are neither loaded nor transmitted. Exact original
source/form/file/rights/native access are rechecked across awaits. No app financial schema is added.

The existing fixed owned identity service is separate from configurable synchronization destinations. No provider
request occurs on page load, selection or preview. Metadata checks/offers contain no financial payload. Sending
requires the native recipient/provider/model/maximum-unit confirmation plus existing export authentication. The
private original request is saved before HTTP. Historical display retains original destination/terms/packet;
cached historical balances cannot overwrite current authoritative wallet metadata. Model output is bounded to
4,000 characters, finite UTF-8, no control/bidi override spoofing, and a native read-only text surface.

Service states are Pending, Completed, Refunded and NotAccepted. A timeout/unknown outcome retains reservation;
only definitive original provider evidence settles actual charge or refunds. Not-found at a provider is Unknown.
An explicit client continuation checks status first and may send only the exact saved packet/id when absent at
the service. Metadata-only close creates a durable unaccepted closure, so a late original packet cannot start
later; accepted work is neither recalled nor guessed refunded. A single immutable offer cannot authorize two
requests. A trusted receipt/gift port is internal only, globally deduplicates the original grant identity and
never accepts client-chosen units or subscription entitlement. Purchased credit never automatically expires.
The service owner lock spans reservation/write transactions, never network I/O; a stable per-owner request hash
names the original provider operation. Actual provider idempotence/status/reconciliation must be qualified before
live activation, including service restoration/uncertainty and identity erasure/retention policies.

Private app state is outside financial/portable storage, stored through platform SecureStorage with a public
loss marker; no credential or API key is collected. Loss refuses fresh sends rather than clearing an uncertain
original. This does not claim full private-state recovery after key loss, OS/OEM transfer or power loss. Android's
existing final all-domain OS-backup exclusions cover these private slots/markers. Native iOS/keychain and its
final backup policy remain actual Mac work. Official platform reference:
[SecureStorage](https://learn.microsoft.com/en-us/dotnet/maui/platform-integration/storage/secure-storage?view=net-maui-10.0).
