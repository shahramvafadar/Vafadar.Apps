# Android development screenshot drafts (D-624)

Eight actual Android frames in each existing language. These are development drafts of the
completed D-621 offline package on a fresh API36/x64/4096 emulator, not a selected release,
physical-device acceptance or Store submission. The historical Windows set is unchanged.
All48 files are1080x1920 truecolor RGB PNGs. Native pixels, clocks, keyboards and viewport
limits are preserved; only entirely opaque alpha is omitted, with exact RGB-byte equality.
[Provenance](capture-manifest.json) and [quality report](../../../quality/android-store-drafts.md).

The fictional user-authored Demo names remain English in every language. The new set shows
upcoming unpaid monthly plans and checking/cash accounts; it does not claim an overdue plan,
a visible loan, the offscreen savings row, all editor fields or every report chart. The goal
is saved and pinned below the initial Home viewport, not promised as visible in these frames.
One unfinished German IME frame was rejected and replaced; all47 successful originals remain.
An actual French-navigation ANR and the visible dark-progress white corner slivers remain
unresolved and are documented. Do not use this asset set to mark stability, accessibility,
all responsive layouts, final promotional composition or public release accepted.
