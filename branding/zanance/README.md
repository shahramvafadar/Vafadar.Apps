# Zanance brand assets

The Zanance symbol as a vector master, reconstructed from the approved reference image, and every export made from
it. The master (geometry `ffae7f2ee01a0705`) was approved by the owner on 2026-09-28 (decision D-26 in
`src/Apps/Zanance/docs/01-assessment-and-decisions.md`).

| Folder | Content |
|---|---|
| `references/approved/` | The only geometry reference; never modified (`SHA256SUMS.txt`, `SOURCE_AUDIT.json`) |
| `source/` | `geometry.json` and `zanance-symbol-master.svg` – the single source of every output |
| `exports/` | SVG, PNG, WebP, PDF, EPS and ICO in colour, mono and lockup variants |
| `platform-candidates/` | Review images per platform |
| `previews/` | Review page, renderer comparison, `app-assets.png` (what the MAUI build generated) |
| `reports/` | Quality report, manifest, draft guidelines and tokens, integration record |
| `scripts/` | Reproducible Node pipeline, see [scripts/README.md](scripts/README.md) |
| `tools/` | SVG structure check |

The app icon, splash images, Android notification icon and in-app symbol in `src/Apps/Zanance/Vafadar.Zanance.App` are
generated by `scripts/integrate.mjs`; do not edit them by hand and do not redraw the logo.
